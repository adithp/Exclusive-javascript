# Exclusive-javascript 🛍️

A minimalist and fully responsive product showcase website built entirely using core front-end technologies: **HTML, CSS, and JavaScript**.

This project focuses on clean design and fundamental JavaScript to handle dynamic interactions, making it an excellent resource for learning static site architecture.

---

## ✨ Features

* **Product Listing Page:** Displays a catalog of items (`product-list.html`).
* **Product Detail View:** Dedicated page for detailed information on a single item (`product-detail.html`).
* **Exclusive Theming:** A clean, visually appealing design focusing on a premium user experience.
* **Vanilla JavaScript:** All dynamic functionality is handled using pure JavaScript, without frameworks.

## 🛠️ Technology Stack

| Technology | Purpose |
| :--- | :--- |
| 🌐 **HTML5** | Core structure and semantic markup. |
| 🎨 **CSS3** | Styling and responsive design. |
| 💡 **JavaScript** | Handling interactions, data, and dynamic content changes. |

---

## 🚀 Getting Started

To view and interact with this project locally, simply follow these steps. No server or build process is required!

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/adithp/Exclusive-javascript.git](https://github.com/adithp/Exclusive-javascript.git)
    ```
2.  **Open the file:**
    Navigate to the cloned directory and open **`index.html`** or **`product-list.html`** directly in your web browser.
